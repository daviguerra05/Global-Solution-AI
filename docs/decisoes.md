# Decisões de escopo confirmadas pelo aluno

- Tema: energia; assistente de uso consciente de energia residencial, com orientações gerais para o Brasil.
- MVP: interface Streamlit com simulação de ingestão de dados, consumo por equipamento e perguntas à API local.
- Fontes: publicações públicas adequadas, selecionadas e atribuídas pelo projeto.
- Hardware: Intel Core i7-13620H, 16 GB de RAM e Intel UHD Graphics; treinamento e execução em CPU, neste computador.
- Comparação: mesmo SmolLM2-135M-Instruct original, RAG simples e RAG com LoRA. O tamanho foi escolhido pelo piloto local, para caber no hardware disponível.
- Repositório: somente Git local nesta pasta. O aluno fará a publicação manual no GitHub.
- Vídeo: gravação posterior pelo aluno; fora da implementação solicitada nesta etapa.
- Não foram fornecidas orientações adicionais às do PDF da atividade.
